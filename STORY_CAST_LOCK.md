# Story Cast Lock

## Scope
- Canonical Season 1 alpha cast list and fixed NPC profile targets.
- This file owns profile values; other docs should reference, not copy them.
- Character bios and grounding writeups live in `story/characters/`.

## Core Rule (Non-Negotiable)
- Only the `player character` uses a progression/stat growth system.
- All NPCs use fixed profile targets tuned by design + playtesting.

## Profile Model
Profile axes are design-time tuning values, not progression stats:
- `power`
- `technical`
- `spin`
- `composure`

Tuning guardrails:
- No hyper specialists.
- NPCs remain well rounded with mild signature bias.
- Keep NPC values in roughly `0.45..0.75`.

## Narrative Tone Constraints for Cast
- No caricature villains.
- Conflicts are friction and mismatch, not moral extremes.
- Emotional movement should primarily surface through play behavior.

## Change Policy
- Do not add/remove core cast members before anchor beat mapping is complete.
- Any profile change should be justified by playtesting notes.
