# Character Workspace

This folder stores canonical character development artifacts.

## Structure
- `INDEX.md`: roster and completion status.
- `bios/`: stable implementation-facing character files.
- `writeups/`: long-form grounding narratives.
- `art/`: portrait and sprite direction briefs for artists.

## Rules
- All character work in this folder must follow `STORY_CHARACTER_DEVELOPMENT_RULES.md`.
- Use `writeup` first, then extract to `bio`.
- Default writeup order:
  - Grounding Story 01
  - Grounding Story 02
  - Grounding Story 03
  - present-age beliefs/values section
- Explicit exceptions are allowed only by direct project direction and must be recorded in-file.
- Keep bio facts stable and testable against scene usage.
